## Overview

This guide will teach you how to successfully track how your groups (workspaces, departments, projects, etc.) are being used in your product. You can associate events with multiple groups simultaneously, creating a hierarchy of relationships. For example, you can track an event that belongs to a specific workspace, department, and project all at once.

<InfoIcon color="purple.400" /> **Note**: If you have already implemented the `.track` call for users, you can just add the
`groups` object within the `properties` with the right group types and group IDs. There is no need to add additional `.track` calls for groups.

## Code

Replace `USER_ID` with your user identifier, and include a `groups` object within the `properties` with the right group types and group IDs. You can associate events with multiple group types by including their respective IDs.
