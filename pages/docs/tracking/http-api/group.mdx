## Endpoint
```js
POST https://api.june.so/sdk/group
```

## Purpose
This action is used to track the identification of a group.

## Response
Returns a JSON response with a status of `200` and a `success` key set to `true`.

```json
{
  "status": 200,
  "success": true
}
```
